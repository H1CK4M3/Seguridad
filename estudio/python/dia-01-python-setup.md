##Declaracion de variables

La funcion de una variable es el almacenamiento de datos para ser utilizados luego por la aplicacion en python las variables son dinamicas lo que permite que no haya que declarar el tipo de variable a la hora de declararla solo es necesario nombrar la variable y asignarle un valor a la misma

f-string - Es un metodo que facilita la concatenacion de texto solo tiene que al inicio del print iniciar con una f fuera de las "" y luego llamas a las variables con un para de {}
