# Inversa a Crackme

## Ejercicio

Editar el binario crackme para obtener la contrasena y modificarla para acceder a la app

## Resolucion

1 - Leer el binario a ver si se descubren documentos o elementos importantes

string <binario>

1 - Instalar la app para realizar ingenieria inversa

sudo apt install hexedit

2 - Buscar en el texto parametros que puedan ser de interes como posibles 
contrasenas incluidas en el propio codigo de la app

3 - Instalar la segunda app para realizar ingenieria inversa

## Problemas

1 - La app hexedit me dio problemas a la hora de realizar busqueda de string por lo que 
instale hexcurse

2 - En la app hexcurse modifico la contrasena pero no se me almacena la nueva que puse sino la que le de la gana

## Notas importantes 

1 - En el editor hexadecimal debe de coincidir la cantidad de caracteres de la contrasena vieja
con los de la nueva debe de ser exactamente la misma
